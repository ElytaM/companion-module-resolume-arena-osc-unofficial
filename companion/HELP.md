### Версия 2.1.1: две Arena, thumbnails и очистка оформления

В Connection Settings можно включить **Arena 2 (UDP)** и указать второй IP, порт отправки OSC, отдельный порт обратной связи и REST-порт. Старые конфигурации продолжают работать без изменений.

Живой слот запоминает Arena, в которой был выбран клип или column. При включённой второй машине маркер `¹`/`²` показывает адресата. Action Manager сохраняет машину для каждого действия, поэтому одна кнопка может управлять обеими Arena.

Thumbnail загружается при назначении клипа. Для обновления: **PAINT → THUMB → заполненный слот клипа**; PAINT показывает `THUMB READY`. Изображение занимает всю высоту кнопки, свободное поле остаётся чёрным. **PAINT → 🧱 CLEAR → слот** удаляет цвет и thumbnail, сохраняя действие. REST ограничен read-only endpoint thumbnail; команды через REST не выполняются.

Для стандартного имени `Column #` модуль выбирает самый длинный непустой клип колонки и показывает `C1` и `(1.1 ролик Пермь)` на следующей строке. Скобки означают автоматическое имя.

Управляйте Resolume Arena с физических кнопок и энкодеров через OSC. Работает по локальной сети без дополнительных плагинов.

### Настройка

1. В **Resolume Arena**: Preferences → OSC
   - **OSC Input port** — порт, на который Companion отправляет команды (по умолчанию **7000**)
   - **OSC Output / Feedback port** — порт, на котором Arena отправляет обратную связь (по умолчанию **7001**)
2. Добавьте новое подключение в Companion — найдите **Arena (osc-only)**
3. Введите **IP-адрес** компьютера с Arena. `127.0.0.1` работает только если Companion и Arena на **одном ПК**
4. Включите **Listen for Feedback** для обратной связи (переменные, цвета, прогресс-бары)
5. **Tempo / BPM**: укажите реальный диапазон темпа Arena (по умолчанию 20–500). Если Arena не нормализует темп — включите **Tempo uses actual BPM value**
6. На нестабильных сетях выключите **Enable real-time clip progress polling** — счётчики клипов продолжат работать, но без периодического пере-опроса позиции

### Действия (Actions)

#### Произвольные OSC-команды

- **Send without arguments** / **Send integer** / **Send float** / **Send string** / **Send boolean** / **Send blob**
- **Send multiple arguments** — перечислите через пробел: `1 "текст" 2.5`

#### Управление клипами и колонками

| Действие | Что делает |
|---|---|
| Trigger clip | Запустить клип по номеру слоя и клипа |
| Select clip | Выделить клип без запуска |
| Trigger column | Запустить колонку |
| Select column | Выделить колонку без запуска |
| Clear layer | Остановить воспроизведение на слое |
| Trigger / Select group column | Запустить или выделить колонку внутри группы |

#### Параметры слоёв и композиции

| Действие | Что делает |
|---|---|
| Layer opacity | Прозрачность видео слоя (0.0–1.0) |
| Layer bypass | Вкл / выкл / toggle bypass слоя |
| Master composition opacity | Общая прозрачность (0.0–1.0) |
| Set BPM | Задать темп — нормализуется в диапазон из настроек подключения |
| Tap tempo | Тап-темпо |
| Set audio volume | Громкость (0.0–1.0), опционально с плавным переходом 400мс |
| Set composition speed | Скорость (0.0–1.0), мгновенно |
| Set layer transition duration | Длительность перехода слоя (0–10с) |

#### Velocity-энкодеры

Каждое вращение применяет небольшой шаг; шаг автоматически растёт при быстром вращении.

**Модель движения:**
- **Momentum** — каждое нажатие добавляет +0.18 к импульсу (макс. 1.0). Импульс затухает с полупериодом ~300мс. ~8 быстрых поворотов → выход на полную скорость. Первое нажатие — всегда мягкий старт.
- **EMA интервала** (α = 0.25) — сильное сглаживание; случайные всплески не влияют на шаг.
- **Range scaling** (для **OSC: Float nudge**) — шаг пропорционален ширине диапазона. Узкий диапазон (0.2–0.4, ширина 0.2) → шаг в 5 раз мельче; широкий (0–10) → в 10 раз крупнее. Одинаковое число поворотов всегда покрывает весь заданный диапазон.

Готовые пресеты — перетащите на поворотную кнопку:
- **Audio Volume Encoder** — громкость
- **Composition Speed Encoder** — скорость
- **Master Opacity Encoder** — прозрачность мастера
- **Generic Float Encoder** — шаблон для любого OSC-float параметра (цвет, эффект и т.д.)

Для **Generic Float Encoder**: откройте шаги `rotate_right` / `rotate_left`, замените `/osc/path` на нужный OSC-путь. Настройте `Range min` / `Range max` — шаг автоматически масштабируется под диапазон.

Действие **[Arena] Control Panel — Slot rotate** назначается на шаги `rotate_left` / `rotate_right` физического энкодера. Параметры: **Slot number** и **Direction**. Пока панель выключена — полный bypass. Пока панель активна:
- **PAINT** открыт → листает палитру цветов
- VOL / MASTER / SPEED **вооружён** → управляет этим параметром с любой вкладки
- Иначе → переключает вкладки влево/вправо

#### Пресет-слоты

Сохраняйте текущий выбор Arena (клип, колонку или колонку группы) и запускайте одним нажатием.

| Действие | Что делает |
|---|---|
| Preset slot — Trigger / Assign | Пустой → 3с режим быстрого назначения. Заполненный → запустить |
| Edit mode | Режим переназначения (оранжевое мигание) |
| Delete mode | Режим удаления одного слота (красное мигание) |
| Clear slot | Очистить слот напрямую |

> Пресет-слоты сохраняются в конфигурации и не теряются при перезапуске Companion.

#### Автопилот клипа

**Формула:** `автопилот = длительность клипа − переход слоя − сдвиг`

1. Первое нажатие — кнопка показывает результат (жёлтый фон), запрашивает переход у Arena
2. Второе нажатие в течение 8 секунд — отправляет значение в Arena

#### Loop-hold (удержание автопилота)

| Действие | Что делает |
|---|---|
| Loop-start | За 1с до конца цикла увеличивает `autopilot/loops` на 1 — автопилот никогда не срабатывает |
| Loop-fin | Останавливает мониторинг; автопилот сработает в конце текущего цикла |

#### Диагностика

| Действие | Что делает |
|---|---|
| Toggle real-time progress polling | Вкл/выкл пере-опрос позиции клипов без разрыва соединения |
| Check connection (ping) | Замеряет RTT и джиттер; обновляет `arena_ping_ms` / `arena_ping_jitter_ms` |
| OSC Reconnect | Принудительно переоткрывает соединение с Arena |

### Quick Control Panel

Набор кнопок, которые по умолчанию в «bypass» — молчат и не мешают другим индикаторам на той же кнопке. После нажатия активатора превращаются в панель инструментов с 4 вкладками.

**Настройка:**
1. Перетащите **Control Panel — Activate** на кнопку-активатор
2. Перетащите **Control Panel — Slot 1…N** на соседние кнопки (`N` = **Number of control slots**, 2–8, по умолчанию 4)
3. Нажмите активатор → панель включилась; **последний слот** на каждой вкладке — кнопка **NEXT ▶** с номером текущей вкладки (например `2/4 ▶`)

**Переключение вкладок:**
- Нажать **NEXT ▶** — следующая вкладка по кругу
- Повернуть физический энкодер с `arena_control_slot_rotate` — прокрутка вкладок вперёд/назад (как листание цветов в PAINT)

#### PAINT — цветная маркировка слотов

1. Нажать **PAINT** → все слоты панели становятся цветными образцами
2. Листать цвета — кнопкой NEXT или поворотом энкодера
3. Нажать нужный цвет → цвет «вооружён», кнопка показывает `PAINT READY`
4. Нажать любой **заполненный** пресет-слот → он окрасится в выбранный цвет навсегда

---

#### ACT MGR — мульти-команды одним нажатием

До 3 дополнительных OSC-команд срабатывают вместе с основным триггером слота.

1. Нажать **ACT MGR** → панель ждёт выбора слота (`PICK SLOT`)
2. Нажать заполненный пресет-слот → открывается режим просмотра
3. В режиме просмотра:
   - Нажатие слота с командой — **удаляет** её
   - Нажатие пустого слота — **добавляет** текущий выбор Arena
   - Последний слот — EXIT
4. После записи кнопка слота показывает имя + метки всех команд (до 4 строк)

> Прогресс-бар для слота с несколькими командами отключается автоматически.

---

#### VOL / MASTER / SPEED MENU — редирект энкодеров

Пока инструмент **вооружён** (горит зелёным), физический энкодер с `arena_control_slot_rotate` или с флажком **Menu active guard** управляет нужным параметром — с любой вкладки, не важно на какой странице вы сейчас.

Нажать инструмент повторно → снять вооружение, энкодер возвращается к прокрутке вкладок.

**Menu active guard** (флажок в действиях nudge, включён по умолчанию):
- Панель **не активна** → обычное действие энкодера
- Панель **активна** + вооружён параметр → управляет им
- Панель **активна**, ничего не вооружено → действие игнорируется

Переменные Companion для условий:
- `$(arena-osc:arena_control_panel_active)` — `1` пока панель открыта
- `$(arena-osc:arena_rotary_target)` — `volume` / `master` / `speed` / пусто

#### MOVE SLOT — перемещение пресет-слотов

Позволяет перенести все действия одной кнопки на другую.

1. Нажать **MOVE SLOT** → все заполненные слоты начинают **мигать зелёным**
2. Нажать **исходный** слот (что переносим) → он выделяется голубым
3. Нажать **целевой** слот:
   - Слот **пуст** → данные перемещены, режим завершён
   - Слот **занят** → панель показывает варианты разрешения конфликта:
     - `OVERWRITE` — целевой слот заменяется данными источника
     - `MERGE` — основное действие источника добавляется к целевому как дополнительная команда
     - `FROM / INTO` — подсказки с именами слотов
     - `CANCEL (NEXT ▶)` — отменить конфликт, выбрать другую цель

> Нажать исходный слот ещё раз — отменить выбор и вернуться к «выбору источника».<br>
> Нажать **MOVE SLOT** ещё раз — полностью выйти из режима.<br>
> Дополнительные действия (ACT MGR) **не перемещаются** вместе с основным при MERGE — они сохраняются у целевого слота независимо.

#### VERIFY SLOTS — проверка актуальности пресет-слотов

Полезно, например, когда вы добавили или убрали колонку в Arena и часть кнопок перестала вести к нужным клипам.

1. Нажать **VERIFY SLOTS** → кнопка показывает `SCAN… ▶`, модуль поочерёдно опрашивает все слоты
2. После сканирования:
   - Кнопки в норме — продолжают отображаться обычно
   - Кнопки с несоответствием — **мигают красным**
   - Кнопка VERIFY показывает количество проблемных слотов (`VERIFY ⚠ 3`)
3. Нажать **красную** кнопку → она становится янтарной (выбрана для исправления)
4. В Arena **кликнуть нужный клип/колонку** (тот, куда кнопка должна вести)
5. Панель управления обновляется в реальном времени:

| Слот панели | Что делает |
|---|---|
| SET HERE | Исправить только этот слот |
| FIX ALL `+Δ` | Исправить этот слот **и** применить то же смещение ко всем остальным красным кнопкам того же типа. Смещение показывается в кнопке по мере навигации в Arena (`+1 col`, `L+2 C+1` и т.д.) |
| SKIP | Убрать красное мигание с этого слота, не исправляя |
| END VERIFY | Выйти из режима проверки |

> **FIX ALL** применяет смещение только если имя клипа на новой позиции совпадает с ожидаемым. Кнопки, для которых это не так, остаются красными.<br>
> Дополнительные команды (ACT MGR) **не трогаются** при исправлении — только основной адрес слота.

#### User Var 1 / User Var 2 — личные переключатели

Две кнопки для ваших собственных нужд — например, переключение режима вызова, вкл/выкл дополнительного оборудования, любой флаг.

- Нажать → переключить `true` ↔ `false`
- Зелёный = `is true`, серый = `is false`
- Имя кнопки задаётся в настройках подключения (**User var 1 label** / **User var 2 label**, по умолчанию `v=1` / `v=2`)
- Значение доступно как переменная Companion: `$(arena-osc:user_var_1)` / `$(arena-osc:user_var_2)` — `"1"` или `"0"`
- Индикатор **User variable state** позволяет подсветить любую другую кнопку зелёным когда переменная включена

### OSC-ретранслятор

Пересылает входящие OSC-сообщения на второй хост (резервный ПК, QLab, TouchDesigner…).

Опция **Filter transport/position and clip-select messages** (включена по умолчанию) блокирует высокочастотные `/transport/position` и клип-фокус события — предотвращает дёрганье на резервной машине.

---

### Удалённое управление через OSC

Требует включённых **Listen for Feedback** и **Enable Remote Control**.

| Путь | Действие |
|---|---|
| `{prefix}/slot/{n}` | Запустить слот n |
| `{prefix}/slot/{n}/assign` | Назначить текущий выбор |
| `{prefix}/slot/{n}/clear` | Очистить слот |
| `{prefix}/edit i:1/0` | Вкл/выкл режим редактирования |
| `{prefix}/delete i:1/0` | Вкл/выкл режим удаления |
| `{prefix}/bpm_tap` | Тап-темпо |

Prefix по умолчанию: `/companion`

---

### Подсказки

- Все OSC-пути чувствительны к регистру — Arena молча игнорирует неверный регистр
- Если кнопки показывают красные квадраты после установки — перезапустите Companion
- Модуль не собирает данные и не отправляет ничего в интернет
- BPM «застревает» на максимуме диапазона — проверьте и поправьте **BPM range min/max** в настройках подключения
- Если Arena включает «Update Clip Preview» — это её собственное поведение при появлении OSC-наблюдателя, не команда модуля. Отключите **real-time progress polling** или настройте обновление миниатюр вручную в Arena Preferences → General
