# Arena OSC 1.5.14 — справка

Управляйте Resolume Arena с физических кнопок и энкодеров через OSC. Команды передаются по локальной сети через OSC.

---

### Настройка

1. В **Resolume Arena**: Preferences → OSC
   - **OSC Input port** — порт, на который Companion будет отправлять команды (по умолчанию **7000**)
   - **OSC Output / Feedback port** — порт, на котором Arena отправляет обратную связь (по умолчанию **7001**)
2. В Companion добавьте новое подключение — найдите **Arena (osc-only)**
3. Укажите **IP-адрес** компьютера с Arena и порты
4. Включите **Listen for Feedback** — тогда кнопки будут обновляться в реальном времени (переменные, цвета, прогресс-бары)

---

### Действия (Actions)

#### Произвольные OSC-команды
Отправьте любое OSC-сообщение вручную:
- **Без аргументов** — просто путь
- **Целое число** (int)
- **Дробное число** (float)
- **Строка** (string)
- **Несколько аргументов** — перечислите через пробел, например: `1 "текст" 2.5`
- **Булев тип** (boolean)
- **Бинарные данные** (blob, Base64 или Hex)

#### Управление клипами и колонками
| Действие | Что делает |
|---|---|
| Trigger clip | Запустить клип по номеру слоя и клипа |
| Select clip | Выделить клип в интерфейсе без запуска |
| Trigger column | Запустить колонку по номеру |
| Select column | Выделить колонку без запуска |
| Clear layer | Остановить воспроизведение на слое |
| Trigger group column | Запустить колонку внутри группы |
| Select group column | Выделить колонку группы без запуска |

#### Параметры слоёв и композиции
| Действие | Что делает |
|---|---|
| Layer opacity | Прозрачность видео слоя (0.0–1.0) |
| Layer bypass | Включить / выключить / переключить bypass слоя |
| Master composition opacity | Общая прозрачность композиции (0.0–1.0) |
| Set BPM | Задать темп в ударах в минуту |
| Tap tempo | Нажать тап-темпо (как в интерфейсе Arena) |
| Set audio volume | Задать уровень громкости (0.0–1.0). Опциональный плавный переход 400мс |
| Set composition speed | Задать скорость композиции (0.0–1.0), мгновенно |
| Set layer transition duration | Задать длительность перехода слоя в секундах (0–10с) |

#### Velocity-энкодеры
Чем быстрее вращаете — тем больший шаг. Медленно — точная регулировка.

- **Audio volume nudge** — регулировка громкости (вверх/вниз)
- **Composition speed nudge** — регулировка скорости (вверх/вниз)

Готовые пресеты уже настроены — просто перетащите **Audio Volume Encoder** или **Composition Speed Encoder** на поворотную кнопку.

#### Пресет-слоты
Сохраняйте текущий выбор Arena (клип, колонку или колонку группы) в один из 50 пронумерованных слотов и запускайте одним нажатием.

| Действие | Что делает |
|---|---|
| Preset slot — Trigger / Assign | Пустой слот → 3с режим быстрого назначения. Заполненный слот → запустить |
| Edit mode | Включить режим переназначения слотов (кнопки мигают оранжевым) |
| Delete mode | Включить режим удаления слотов (кнопки мигают красным) |
| Clear slot | Очистить конкретный слот напрямую |

> Пресет-слоты сохраняются в конфигурации подключения и не теряются при перезапуске Companion.

#### Автопилот клипа
Рассчитывает и устанавливает время автопилота клипа на основе его длительности.

Формула: **время автопилота = длительность клипа − переход слоя − дополнительный сдвиг**

Работает в два нажатия:
1. **Первое нажатие** — вычисляет и показывает результат на кнопке (жёлтый фон). Запрашивает актуальное время перехода у Arena.
2. **Второе нажатие** (в течение 8 секунд) — отправляет значение в Arena.

Если в течение 8 секунд второго нажатия не последовало или был выбран другой клип — расчёт сбрасывается.

### OSC-ретранслятор

Включите ретранслятор чтобы пересылать все входящие OSC-сообщения на второй хост (дублирующий компьютер, QLab, TouchDesigner и т.д.). Модуль только читает сообщения — ничего не блокирует.

#### Фильтр ретранслятора

Опция **Filter transport/position and clip-select messages** (включена по умолчанию) блокирует от пересылки:

| Что блокируется | Почему |
|---|---|
| `/composition/layers/N/clips/M/transport/position/*` | Очень высокая частота (10+ сообщений/сек на каждый активный клип) — вызывает дёрганье картинки на резервной машине |
| `/composition/layers/N/clips/M/selected` | Реакция на фокус интерфейса — резервная машина не должна переключать клипы по щелчку в UI основной |
| `/composition/layers/N/clips/M/select` | Аналогично |

Команды запуска (`connect`), прозрачности, BPM, громкости и всё остальное пересылается без изменений.

### Установка OSC-шорткатов Resolume

Действие **Install Resolume Arena shortcuts file** записывает файл `ARENA-OSC.xml` в папку `Presets\Shortcuts` Resolume Arena на этом же ПК.

ОSC-шорткаты в Resolume управляют тем, что Arena **отправляет** как обратную связь (output). Приём OSC-команд от Companion работает всегда вне зависимости от шорткатов. Шорткаты нужны чтобы Arena слала нужные пути Companion — для работы переменных и индикаторов. Без загруженного пресета Arena либо ничего не отправляет, либо шлёт только то что настроено глобально через «Output All».

1. Нажмите кнопку с действием **Install Resolume Arena shortcuts** — файл появится в `Presets\Shortcuts`
2. В Arena: **Preferences → Shortcuts → Load** → выберите `ARENA-OSC.xml`

### Удалённое управление через OSC

Arena (или любой другой OSC-источник) может управлять слотами и режимами прямо из сцены. Требует включённых **Listen for Feedback** и **Enable Remote Control**.

| Путь | Действие |
|---|---|
| `{prefix}/slot/{n}` | Запустить слот n |
| `{prefix}/slot/{n}/assign` | Назначить текущий выбор в слот n |
| `{prefix}/slot/{n}/clear` | Очистить слот n |
| `{prefix}/edit i:1` / `i:0` | Включить / выключить режим редактирования |
| `{prefix}/delete i:1` / `i:0` | Включить / выключить режим удаления |
| `{prefix}/bpm_tap` | Нажать тап-темпо |

Prefix по умолчанию: `/companion`

### Автоматизация: Clip End Trigger и Loop-Hold

> Требует **Listen for Feedback** — модуль должен получать `/transport/position` от Arena.

#### [Arena] Clip end — trigger clip

Вооружает одноразовую ловушку на слое. Как только оставшееся время клипа на этом слое достигает порогового значения (по умолчанию 0.3с), модуль отправляет `connect` на целевой клип.

| Параметр | Описание |
|---|---|
| Watch layer | Слой, на котором ожидается конец клипа |
| Target layer | Слой, куда запустить следующий клип |
| Target clip | Номер клипа для запуска |
| Threshold | За сколько секунд до конца срабатывать (0.1–5с, по умолчанию 0.3с) |

Срабатывает один раз и снимается автоматически. Повторное нажатие кнопки перевооружает. Для отмены — действие **Clip end — cancel trigger**.

#### [Arena] Loop-start / Loop-fin

Кнопка **loop-start** запускает непрерывный мониторинг клипа. За 1 секунду до конца каждого цикла модуль прибавляет +1 к значению `/autopilot/loops` — счётчик автопилота уходит вперёд, и автопилот никогда не достигает порога срабатывания. Клип будет зациклен до тех пор, пока не нажата кнопка **loop-fin**.

Кнопка **loop-fin** останавливает мониторинг. Автопилот сработает в конце текущего или следующего цикла штатно.

| Параметр | Описание |
|---|---|
| Watch layer | Слой с клипом |
| Watch clip | Номер клипа (для пути `autopilot/loops`) |

### Подсказки

- Все OSC-пути чувствительны к регистру — Arena молча игнорирует неверный регистр
- Если после установки кнопки показывают красные квадраты — перезапустите Companion
- Модуль не собирает данные и не отправляет ничего в интернет
