# Arena OSC 1.5.14

Добавлены инструменты для отслеживания воспроизведения и настройки автопилота.

- Прогресс клипа и оставшееся время на кнопках.
- Расчёт автопилота: длительность клипа минус переход слоя и дополнительный сдвиг.
- Подтверждение расчёта повторным нажатием.
- Loop-start и Loop-fin для удержания клипа в цикле.

## Установка

Импортируйте `arena-osc-1.5.14.tgz` через **Settings → Modules → Install from file**. Архив `.zip` предназначен для ручной установки. После установки перезапустите Companion.

Описание версии: https://github.com/ElytaM/ARENA-OSC/releases/tag/v1.5.14
