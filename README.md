# Arena OSC

Модуль для управления Resolume Arena из Bitfocus Companion через OSC. Позволяет запускать клипы и колонки, сохранять их на кнопках и управлять параметрами с энкодеров.

## Возможности

- Запуск и выбор клипов, колонок и колонок внутри групп.
- Сохраняемые слоты: назначение из Arena, переименование, цветовая маркировка и перемещение между кнопками.
- До трёх дополнительных действий на одном слоте.
- Управление громкостью, скоростью, прозрачностью и BPM с кнопок и энкодеров.
- Прогресс воспроизведения, оставшееся время, автопилот и удержание клипа в цикле.
- Проверка назначений после изменения композиции, в том числе автоматическая.
- Работа с двумя компьютерами Arena и ретрансляция OSC на резервные машины.
- Миниатюры клипов на кнопках и диагностика соединения.

Команды управления передаются по OSC. Миниатюры загружаются через REST API Arena; их можно отключить в настройках подключения.

## Установка

Для текущей версии нужны **Bitfocus Companion 5** и **Resolume Arena с поддержкой OSC**. Модуль проверен с Arena 7.

1. Скачайте `arena-osc-2.1.9.tgz` из [последнего релиза](https://github.com/ElytaM/ARENA-OSC/releases/latest).
2. В Companion откройте **Settings → Modules → Install from file** и выберите `.tgz`.
3. Перезапустите Companion и добавьте подключение **resolume: arena (only osc)**.

Для ручной установки в Windows скачайте `.zip` из того же релиза и распакуйте папку модуля в `%APPDATA%\companion\modules\` и перезапустите Companion.

## Подключение к Arena

В Arena откройте **Preferences → OSC** и настройте входящие команды и обратную связь. Затем укажите в Companion:

| Настройка | Что указать |
|---|---|
| Target IP | IP компьютера с Arena. Если обе программы на одном компьютере — `127.0.0.1` |
| Target Port | OSC Input port в Arena; по умолчанию `7000` |
| Listen for Feedback | Включите для обновления состояния кнопок и переменных |
| Feedback Port | Порт приёма обратной связи в Companion; по умолчанию `7001` |
| BPM range min / max | Тот же диапазон темпа, что установлен в Arena |
| REST thumbnail port | Порт REST API Arena для миниатюр; по умолчанию `8080` |

В OSC Output Arena задайте адрес компьютера с Companion и соответствующий Feedback Port. Для миниатюр также включите REST API в Arena.

### Назначение кнопок

Добавьте пресеты слотов на страницу Companion. Нажмите пустой слот и в течение трёх секунд выберите клип или колонку в Arena. Назначение сохранится в конфигурации подключения.

Для переназначения используйте **EDIT MODE**, для очистки — **DEL MODE**. Панель управления даёт доступ к цветам (**PAINT**), дополнительным действиям (**ACT MGR**), перемещению (**MOVE SLOT**) и проверке назначений (**VERIFY SLOTS**).

### Две Arena

Включите **Enable Arena 2 (UDP)** и задайте адрес и порты второй машины. У машин должны быть разные Feedback Port. Слот запоминает, в какой Arena был выбран объект; метки `¹` и `²` показывают адресата.

### Миниатюры

Миниатюра загружается при назначении клипа. Обновить её вручную можно через **PAINT → THUMB → слот**. Выбор цвета скрывает миниатюру, а инструмент очистки оформления удаляет цвет и изображение, сохраняя действие слота.

Подробное описание панели, действий, переменных и OSC-команд — в [справке модуля](companion/HELP.md). История изменений находится на странице [релизов](https://github.com/ElytaM/ARENA-OSC/releases).

## Если что-то не работает

- **Нет реакции на команды:** проверьте IP, OSC Input port и разрешение UDP-трафика в брандмауэре.
- **Кнопки не обновляются:** включите Listen for Feedback и проверьте OSC Output Arena.
- **BPM становится максимальным:** сравните BPM range min / max с диапазоном в Arena.
- **Не появляются миниатюры:** проверьте доступность REST API и REST thumbnail port.
- **Высокая нагрузка на сеть:** отключите Enable real-time clip progress polling.

Сообщить о проблеме можно в [Issues](https://github.com/ElytaM/ARENA-OSC/issues). Укажите версии Companion, Arena и модуля, настройки подключения без личных данных и шаги для повторения ошибки.

## Сборка

Нужны Node.js 22 и npm.

```sh
npm ci
npm test
npm run build
```

`npm run release` собирает модуль, запускает тесты и создаёт установочные `.zip` и `.tgz` в `release/`. Скрипт упаковки использует PowerShell и рассчитан на Windows. Копия отслеживаемых исходников помещается в `dist/`.

`npm run deploy` копирует готовую сборку в папку модулей Companion текущего пользователя в Windows.
