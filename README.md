# Arena OSC 2.0.1

Модуль переведён на API Companion 5.

- До пяти OSC-ретрансляторов.
- Отрисовка индикаторов с учётом размера кнопки.
- Обновлённая работа энкодеров и панели управления.

Для этой и последующих версий нужен Companion 5. Для старых установок доступны релизы ветки 1.x.

## Установка

Импортируйте `arena-osc-2.0.1.tgz` через **Settings → Modules → Install from file**. Архив `.zip` предназначен для ручной установки. После установки перезапустите Companion.

Описание версии: https://github.com/ElytaM/ARENA-OSC/releases/tag/v2.0.1
