# Arena OSC 1.3.0

Базовая версия модуля для подключения Resolume Arena к Companion через OSC.

- Отправка OSC-сообщений с целыми и дробными числами, строками и несколькими аргументами.
- Индикаторы по входящим OSC-сообщениям.
- Переменные с последними отправленными и полученными сообщениями.

## Установка

Импортируйте `arena-osc-1.3.0.tgz` через **Settings → Modules → Install from file**. Архив `.zip` предназначен для ручной установки. После установки перезапустите Companion.

Описание версии: https://github.com/ElytaM/ARENA-OSC/releases/tag/v1.3.0
