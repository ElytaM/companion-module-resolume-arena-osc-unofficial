# Arena OSC 1.4.2

Назначение клипов и колонок на кнопки Companion из текущего выбора в Arena.

- Слоты сохраняются при перезапуске Companion.
- Режимы редактирования и удаления назначений.
- Управление колонками внутри групп.
- Энкодеры с шагом, зависящим от скорости вращения.
- Ретрансляция OSC и удалённое управление слотами.

## Установка

Импортируйте `arena-osc-1.4.2.tgz` через **Settings → Modules → Install from file**. Архив `.zip` предназначен для ручной установки. После установки перезапустите Companion.

Описание версии: https://github.com/ElytaM/ARENA-OSC/releases/tag/v1.4.2
