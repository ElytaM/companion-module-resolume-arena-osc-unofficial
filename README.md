Модуль для управления **Resolume Arena** через OSC из Bitfocus Companion. Физические кнопки, энкодеры, прогресс-бары, автопилот — всё в одном модуле без плагинов и лишних программ.

> Управление работает только по OSC. REST разрешён исключительно для чтения thumbnail; телеметрии нет.

## Возможности

- **Запуск клипов и колонок** — по номеру слоя и клипа
- **Поддержка групп** — запуск и выделение колонок внутри групп Resolume
- **Управление слоями** — прозрачность, bypass, очистка
- **Мастер-прозрачность и BPM** — установка и тап-темпо
- **Переход слоя** — установка длительности перехода (0–10 секунд)
- **Пресет-слоты** — сохраните текущий выбор Arena и запускайте одним нажатием; слоты не теряются при перезапуске Companion
- **Режим редактирования и удаления** — переназначайте и очищайте слоты с визуальным миганием кнопок
- **Удалённое управление через OSC** — Arena (или любой OSC-источник) может управлять слотами прямо из сцены
- **OSC-ретранслятор** — пересылает входящие сообщения на второй хост параллельно; встроенный фильтр блокирует transport/position и clip-select сообщения (предотвращает дёрганье картинки на резервной машине)
- **Velocity-энкодеры** — чем быстрее крутите, тем больший шаг; EMA-сглаживание для плавного ощущения
- **Плавное изменение громкости** — 400мс рампа чтобы избежать резких скачков
- **Автопилот клипа** — рассчитывает время автопилота по формуле `длительность − переход − сдвиг`, двойное нажатие для подтверждения
- **Loop-start / Loop-fin** — задерживает автопилот нажатием кнопки: клип зациклен до нажатия loop-fin, после чего автопилот срабатывает штатно
- **Настраиваемый диапазон BPM** — темп нормализуется в диапазон вашей Arena (исправляет ошибку «всегда 500 BPM»); есть опция для абсолютного значения
- **Переключаемый контроль прогресса** — отключает частый пере-опрос позиции клипов для сетей с высокой загрузкой/задержкой
- **Диагностика соединения** — измерение пинга и джиттера OSC-канала одним нажатием
- **Quick Control Panel** — набор кнопок в режиме bypass (простой) до активации, затем — быстрые инструменты: покраска слотов, массовое удаление, пинг, переключение опроса прогресса
- **Полная OSC-обратная связь** — переменные для BPM, громкости, скорости, выбранного клипа/колонки, состояния слоёв, транспорта и многого другого

## Установка

### Из ZIP-файла (рекомендуется)

1. Скачайте `arena-osc-1.7.3.tgz` (или `.zip`) со страницы [Releases](../../releases)
2. В Companion: **Settings → Modules → Install from file**
3. Выберите ZIP — Companion установит автоматически
4. Перезапустите Companion
5. Добавьте новое подключение: найдите **Arena (osc-only)**

### Вручную

1. Распакуйте архив в папку `%APPDATA%\companion\modules\arena-osc-1.7.3\`
2. Перезапустите Companion

## Настройка подключения

| Поле | Значение по умолчанию | Описание |
|---|---|---|
| Target IP | — | IP-адрес компьютера с Resolume Arena |
| Target Port | 7000 | OSC Input порт в Arena (Preferences → OSC) |
| Listen for Feedback | выкл | Включить для получения значений от Arena (нужно для переменных и индикаторов) |
| Feedback Port | 7001 | Порт на котором Arena отправляет обратную связь |
| Layers (preset count) | 10 | Количество слоёв для предгенерации пресетов прогресс-баров |
| Groups (preset count) | 0 | Количество групп для предгенерации пресетов |
| Enable Relay | выкл | Пересылать входящие OSC на второй хост |
| Relay Host / Port | — | Адрес и порт для ретрансляции |
| Filter transport/position | вкл | Блокировать от пересылки позиции клипа и clip-select события (рекомендуется для резервной машины) |
| Enable Remote Control | выкл | Принимать управляющие OSC-команды от Arena или другого источника |
| Enable real-time clip progress polling | выкл | Периодический пере-опрос позиции клипов для точного отсчёта. Отключите на чувствительных сетях — можно переключать и в рантайм кнопкой |
| BPM range min / max | 20 / 500 | Диапазон темпа в настройках Arena (Composition → Tempo Controller). Должен совпадать с реальным, иначе BPM будет выставляться неверно |
| Tempo uses actual BPM value | выкл | Включите, если ваша Arena принимает/отдаёт темп напрямую, без нормализации |

## Пресет-слоты

Слоты позволяют сохранить любой текущий выбор Arena (клип, колонку или колонку группы) и запускать его одной кнопкой.

1. Нажмите **пустой слот** → он входит в режим быстрого назначения на 3 секунды (кнопка мигает)
2. Выберите нужный клип или колонку в Arena за эти 3 секунды → сохранится автоматически
3. Или включите **Edit Mode** → нажмите любой слот для переназначения
4. **Delete Mode** → нажмите слот для очистки

Слоты хранятся в конфигурации подключения и не теряются при перезапуске.

## Резервная машина (Backup Setup)

Для работы в паре основная + резервная Arena:

1. В настройках подключения включите **Enable Relay** и укажите IP и порт резервной машины
2. Оставьте включённым **Filter transport/position** — это предотвращает дёрганье картинки на резервной Arena
3. Настройте OSC-вывод резервной Arena: Output host = IP основной машины, Output port = 7001

## Loop-Hold и диагностика

> Loop-hold требует **Listen for Feedback** — модуль читает `/transport/position` от Arena для отслеживания времени.

### Loop-start / Loop-fin

**loop-start** — запускает мониторинг: за 1 секунду до конца каждого цикла модуль прибавляет +1 к `/autopilot/loops`. Счётчик всегда впереди реального значения — автопилот не срабатывает.

**loop-fin** — останавливает мониторинг. Автопилот сработает в конце текущего цикла штатно.

### Диагностика и сетевая нагрузка

- **Toggle real-time progress polling** — быстро вкл/выкл периодический пере-опрос позиции клипов одним нажатием (дублирует настройку подключения)
- **Check connection (ping)** — замеряет время отклика OSC и джиттер (по последним 10 замерам), кнопка меняет цвет по качеству связи

## Quick Control Panel

Кнопки, которые по умолчанию находятся в «bypass» (простаивают, нажатие ничего не делает, можно вывести на них любую другую информацию) — пока не нажата отдельная кнопка-активатор.

**Настройка:**
1. Перетащите пресет **Control Panel — Activate** на кнопку
2. Перетащите пресеты **Control Panel — Slot 1…N** на соседние кнопки (число слотов задаётся полем **Number of control slots** в настройках подключения — от 2 до 8, по умолчанию 4)
3. Нажатие Activate включает панель: слоты показывают инструменты вместо простоя. Последний слот всегда **NEXT** — пролистать следующую страницу инструментов

**Инструменты:**

| Инструмент | Что делает |
|---|---|
| PAINT | Открывает палитру цветов (см. ниже) |
| DEL ALL | Взводится первым нажатием (5 секунд на подтверждение), повторное нажатие удаляет **все** пресет-слоты сразу |
| PING | То же самое что Check connection (ping) |
| POLL TOGGLE | То же самое что Toggle real-time progress polling |
| ADD ACTION | Управление мульти-действиями слота (ACT MGR на панели) |
| EDIT MODE | Вкл/выкл режим редактирования пресет-слотов |
| OSC RECONNECT | Принудительно переоткрывает OSC-соединение |

> ⚠️ PAINT и DEL ALL необратимо меняют/удаляют пресет-слоты.

### Палитра цветов

Нажатие **PAINT** превращает **все** слоты (кроме NEXT) в цветные образцы — колесо из 24 тонов + белый/тёплый белый/серый/чёрный (28 цветов), а не выбор одной кнопкой. **NEXT** листает колесо дальше. Выбор образца «вооружает» цвет — следующее нажатие на заполненный пресет-слот красит его в этот цвет (сохраняется навсегда, переживает перезапуск Companion).

## Автопилот клипа

Автоматически рассчитывает и устанавливает время автопилота так чтобы клип закончился точно в момент начала следующего перехода.

**Формула:** `время автопилота = длительность клипа − длительность перехода слоя − дополнительный сдвиг`

Двойное нажатие для безопасности:
1. **Нажатие 1** — показывает расчёт на кнопке (жёлтый фон), запрашивает актуальное время перехода у Arena
2. **Нажатие 2** (в течение 8 секунд) — отправляет значение в Arena

## Velocity-энкодеры

Перетащите пресет **Audio Volume Encoder** или **Composition Speed Encoder** на поворотную кнопку:

- **Поворот вправо** → увеличить
- **Поворот влево** → уменьшить
- **Нажатие** → сбросить к значению по умолчанию (громкость: 1.0, скорость: 0.25)

Скорость вращения определяет размер шага — медленно для точной регулировки, быстро для охвата всего диапазона.

## Удалённое управление через OSC

Отправляйте команды на порт прослушивания Companion из Arena или любого OSC-источника:

| Путь | Действие |
|---|---|
| `/companion/slot/{n}` | Запустить слот n |
| `/companion/slot/{n}/assign` | Назначить текущий выбор в слот n |
| `/companion/slot/{n}/clear` | Очистить слот n |
| `/companion/edit i:1` / `i:0` | Включить / выключить режим редактирования |
| `/companion/delete i:1` / `i:0` | Включить / выключить режим удаления |
| `/companion/bpm_tap` | Нажать тап-темпо |

Prefix `/companion` можно изменить в настройках подключения.

## Известные особенности

- **BPM всегда становится на максимум** — почти всегда это значит, что диапазон **BPM range min/max** в настройках не совпадает с реальным диапазоном темпа в Arena (Composition → Tempo Controller). Проверьте его и совпадите значения.
- **Arena сама включает «Update Clip Preview» при активном OSC** — это внутреннее поведение Resolume при подключении любого внешнего контроллера, модуль никак его не включает и не запрашивает превью/миниатюры. Если мешает — отключите real-time progress polling или настройте режим обновления миниатюр напрямую в Arena Preferences → General.
