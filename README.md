# Arena OSC 1.6.12

Добавлена панель инструментов для настройки кнопок во время работы.

- Цветовая маркировка слотов.
- Дополнительные действия на одной кнопке.
- Выбор параметра для энкодеров: громкость, прозрачность мастера или скорость.
- Диагностика соединения и переключение опроса прогресса.

## Установка

Импортируйте `arena-osc-1.6.12.tgz` через **Settings → Modules → Install from file**. Архив `.zip` предназначен для ручной установки. После установки перезапустите Companion.

Описание версии: https://github.com/ElytaM/ARENA-OSC/releases/tag/v1.6.12
